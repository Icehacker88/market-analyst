# 模型预测效果诊断（2026-10-17）

作者：Claude Code。没有修改模型代码，没有手动触发 optimizer、Kronos 或任何定时任务。复现完全离线，见文末。

**取数方式说明（2026-10-17 修订）**：本报告的云端数据，是我在 2026-10-17 对正式环境的 `GET /api/predictions/history/{SPY,QQQ,NVDA}` 各请求一次得到的。经 Codex 核对，这个接口会调用 `cloudLedgerHistory → reconcileCloudLedger`，有新结算结果时会调用 `writeCloudLedger`，缓存未命中时还会计算回测并写入响应缓存。所以这些请求不是严格只读的，它们走的是普通访客也会触发的路径。同一天的延迟测量还请求过 `/api/market/snapshot`、`/api/home`、`/api/market/returns`、`/api/forecast/latest`，未命中缓存时同样可能产生计算和缓存写入。后续复核请使用下文的固定导出数据，**不要在正式环境重跑这些请求**。

## 结论（均为待验证的假设）

1. **Safe Mode 所处的期间，网站云端预测明显较差，值得优先排查。** 标为 "Orivane Ensemble Safe Mode" 的记录：1D 命中率 27/72 = 37.5%（48 个日期），5D 22/66 = 33.3%。标为 "Orivane Horizon Router" 的记录：1D 34/66 = 51.5%（36 个日期），5D 38/66 = 57.6%。**这两组覆盖的资产和期间不同**：SPY 的 Router 在 07-16 至 09-03，Safe Mode 在 09-04 至 10-15；NVDA、QQQ 的切换时间又不一样。没有同资产、同日期的对照，所以不能据此认定 Safe Mode 本身更差，也可能是市场阶段不同造成的。
2. **治理逻辑可能让模型在回滚状态停留较久，值得核查。** 按 `evaluateModelGovernance()`（`股票预测/frontend/netlify/functions/api.mts`，产品分支约第 4665–4690 行）的实际代码：
   - 使用的是该资产混合了各种模型的账本，取最近 20 个和 60 个已完成的 1D 样本，**不按 `Best_Model` 区分**。
   - 当最近 20 个样本达到 20 个时：若最近 20 个的方向优势 ≤ −3，或者 60 样本相比 20 样本的准确率下降 ≥ 10 个百分点且最近 20 个优势 ≤ 0，就判为 `rollback`。
   - 若优势 < 1，或准确率下降 ≥ 6，则判为 `watch`；否则为 `stable`。
   - 粘性只在一个条件下生效：上一次是 `rollback`、本次新算出的是 `watch`、且最近 20 个优势 < 3，此时维持 `rollback`。
   - 回滚期间（`safeMode` 分支，约第 5262 行起）不读取官方 Kronos 和叠加信号，也不做调权。
   - 这个机制本身不比较回滚前后两个模型的表现。它是否真的让模型长期停在回滚，需要用治理记录（`model governance` 存储）核实；本报告没有读取这些记录。
3. **Python 日报的 ARIMA 存在看涨偏向。** 账本中 ARIMA 给出 280 条记录，命中 131 条（46.8%），其中 72.1% 预测为涨。全部已结算记录中，实际上涨 191/420 = 45.5%。这里的单位是"资产×日期"记录，覆盖 95 个日期，不是独立交易日的上涨比例。
4. **置信度分数和预测幅度。** 云端 `Confidence_Score` 分三档后，1D 命中率依次为 44.0%、38.0%、49.0%，看不出区分能力。账本中预测幅度最大的四分之一，命中率为 63/105 = 60.0%。

## 局限

- 同一日期的多个资产相关性高，5D、10D、1M 的窗口又互相重叠，有效独立样本比记录数少。没有做显著性检验，本报告不把记录数直接当作独立样本数。
- 模型标签与期间、资产混在一起，缺少同资产、同日期的反事实对照。
- 没有读取治理状态存储，没有重跑模型，也没有拆分 Safe Mode 内部各组成部分的方向。

## 建议（由 Codex 评估；任何改动生产预测逻辑、新增影子计算或写入的方案，都需先经用户同意）

1. 用离线固定样本，或从冻结记录中重建同资产、同日期的 Router/Safe Mode 对照，验证结论 1 是否成立。
2. 读取治理状态的历史记录，核实各资产进入和退出回滚的时间点与原因，验证结论 2。
3. 排查 Safe Mode 期间趋势集成的符号和组合方式。这一期间预测与实际收益呈负相关，值得优先检查。
4. Python 日报：检查 ARIMA 的看涨偏向，以及选模时是否与方向基准做了比较。
5. 置信度分数在重新校准之前，页面上应弱化它的展示。
